KPESH WEBSITE DEMO
==================

- style.css: responsive styling

HOW TO VIEW
1. Extract the ZIP file to a folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Click EN in the top-right corner to switch to English; click বাং to switch back.
